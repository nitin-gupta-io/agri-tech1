# 🌱 AgriTech AI Hackathon Project

## Overview
AI-powered solution for farmers: crop yield prediction + soil health monitoring.

## Features
- Predict crop yield based on soil moisture & temperature.
- Simple dashboard with AI vibes.
- Backend API with Express.

## Tech Stack
- Frontend: HTML, CSS, JS
- Backend: Node.js, Express
- Hosting: Vercel

## How to Run
1. `npm install`
2. `npm start`
3. Open `public/index.html`

## Deployment
Upload ZIP to Vercel → Framework: Node.js → Output: public → Start: npm start → Live URL ready.
